# Speech demo

`robot-alert.wav` says “Robot alert. Prepare for battle.” It was generated locally
with the installed macOS Zarvox voice at 135 words per minute, then converted to
mono 16-bit PCM at 16 kHz. It is a demonstration input, not Berzerk audio and not
an emulation of the arcade speech synthesizer.

The speech lab keeps this source intact for comparison and converts it to four-bit
volume values at the selected rate. Import another recording to compare a different
source through exactly the same TIA playback path.
